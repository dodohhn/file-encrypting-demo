German:

# Datei-Verschlüsselung – Lernprojekt

Ein experimentelles Python-Projekt zum Verschlüsseln und Entschlüsseln von Dateien
mit AES. Das Projekt dient ausschließlich zu Lernzwecken.

> **Wichtig:** Diese Implementierung ist nicht für echte oder wichtige Dateien
> geeignet. Der Schlüssel ist im Quellcode fest eingetragen, und beim
> Verschlüsseln wird die Originaldatei gelöscht. Verwende das Programm nur mit
> entbehrlichen Testdateien.

## Voraussetzungen

- Python 3
- PyCryptodome

## Installation

Installiere die benötigte Bibliothek:

```bash
python -m pip install pycryptodome

```

## Usage

Passen Sie die Ordner- und Dateipfade im Skript an und führen Sie es mit folgendem Befehl aus:

```bash
python script.py
```

Englisch:

# File Encryption – Learning Project

An experimental Python project for encrypting and decrypting files
using AES. This project is intended solely for educational purposes.

> **Important:** This implementation is not suitable for real or important files.
> The key is hard-coded in the source code, and during
> encryption, the original file is deleted. Use the program only with
> disposable test files.

## Prerequisites

- Python 3
- PyCryptodome

## Installation

Install the required library:

```bash
python -m pip install pycryptodome

```

## Usage

Adjust the folder and file paths in the script and run it with:

```bash
python script.py
```
